# Contributing to Sauti Yako

Contributions should strengthen child safety, rights education, accessibility and responsible technology.

## Safety first

- Never commit real child reports or personal data.
- Do not add tracking that is unnecessary for the product.
- Do not treat the frontend as a secure reporting backend.
- Keep content respectful, age-appropriate and privacy-conscious.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Test the change.
4. Explain any privacy or safety implications.
5. Open a pull request.
